One black-and-white newspaper front page summing up six world news stories from 21 November 2026.
Drawn locally with Pillow using simple shapes and a strict grayscale palette.
The lead story covers the Russian missiles that landed in Poland, followed by five shorter columns.
Run `python3 draw.py` to regenerate `entry.png` at 1024x1024.
`main.py` copies that image into `MAKEFUN_OUTPUT_DIR`.
